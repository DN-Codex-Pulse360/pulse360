# Public Regional Example Pack

This sample pack replaces the older fictional `Pacific` storyline with public named examples
anchored in Singapore and the Philippines.

## Included anchors
- `Singtel Group` for Singapore continuity
- `Ayala Corporation` for Philippine conglomerate coverage
- `JG Summit Holdings, Inc.` for Philippine contrast and digital transformation evidence

## Evidence packet rules
- Each account has legal/annual-report, hierarchy/portfolio, and public-signal coverage.
- Every source is public and attributable.
- `accessed_at` is fixed to `2026-03-28T00:00:00Z` for repeatable sample payloads.
- GPT enrichment is explicitly marked as a model-generated summary of public evidence.
